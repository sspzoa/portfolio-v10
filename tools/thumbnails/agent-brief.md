# Claude Code ACP 작업 지시 템플릿

아래의 대괄호만 채워 Claude Code ACP 작업에 전달한다. 실행 환경과 포트폴리오 레포 위치도 함께 제공한다.

```text
프로젝트 [이름]의 포트폴리오 커버를 만든다.
원본 저장소: [저장소]
포트폴리오에 소개하는 활동 시점 또는 커밋: [시점/커밋]
최종 입력 파일 위치: tools/thumbnails/projects/[slug]/

먼저 tools/thumbnails/README.md와 capture-guide.md를 읽고, 실제 포트폴리오의
tokens.css, projects.tsx, detail-dialog.tsx 및 갤러리 화면을 확인한다.
최종 v5 템플릿의 절제된 디자인을 유지하고 사이트의 노란색 포인트는 추가하지 않는다.

라이브 화면이 있으면 실제 화면을 캡처한다. 없다면 활동 시점의 원본 코드를 실행한다.
모양을 비슷하게 다시 구현하지 않는다. 외부 연동과 사용자 데이터만 익명 데모로 대체한다.
Flutter는 원본 SDK 버전을 확인하고 작업 폴더 안에 설치한다.
원본 UI, 폰트, 아이콘, 여백과 문구는 그대로 둔다. 없는 기능을 만들어 넣지 않는다.

핵심 화면 2~3개를 고해상도로 캡처하고 파일명을 기능에 맞게 붙인다.
데스크톱 1440x900 @2x, 모바일 390x844 @3x를 기본으로 하되 실제 앱 비율을 우선한다.
로고는 원본 SVG를 우선하며 도형에 맞게 캔버스를 채운다. 임의 배경을 추가하지 않는다.

presets.json에 구도를 추가하고 render.py로 1600x900 PNG를 만든다.
1600px 원본, 332px 일반 카드, 688px 대표 카드에서 확인한다.
큰 제목 영역과 작은 부제, 기간, 팀 인원은 넣지 않는다. 새 문구에는 중간점을 쓰지 않는다.

source.json에 원본 커밋, 캡처 경로, 실제 파일 크기, 데모 데이터 변경 범위,
원본과 비교한 근거, 확인하지 못한 동작을 기록한다. 임시 경로나 키에 의존하지 않게 한다.
다른 작업의 파일과 세션은 건드리지 않는다. 작업이 끝나면 본인이 띄운 서버,
에뮬레이터와 브라우저 세션만 종료하고 임시 SDK 정리 대상을 보고한다.

결과로 원본 캡처, 로고, 프리셋, 커버, 갤러리 미리보기와 출처를 제공한다.
Notion 업로드 여부와 원본 코드 수정 여부를 명확히 구분해 보고한다.
```
